# Phase 0 스파이크 — DART 편집기 허용성 체크리스트

**목적**: 앞으로 만들 "엑셀에서 표 추가·삭제, 주석 번호 변경, 기수 롤포워드" 기능이
쓰는 파일 조작 방식을 DART 편집기가 받아들이는지 확인합니다. 이 결과가 Track A
구현의 안전 규칙을 확정합니다 (결과는 docs/DART호환성체크리스트.md 로 정리 예정).

**대상 파일** (spike/ 폴더, 원본: A사 분기검토보고서):

| 파일 | 조작 내용 | 편집기에서 볼 위치 |
|---|---|---|
| `V1_표복제삽입.dsd` | 주석 17(특수관계자) 마지막 표를 복제해 바로 뒤에 삽입 — 복제 표 첫 칸에 "(스파이크 복제)" 표시 | 주석 17 끝부분 |
| `V2_표삭제.dsd` | 주석 5(공정가치)의 마지막 표 1개 삭제 | 주석 5 |
| `V3_주석재번호.dsd` | 주석 15·16·17 제목 번호를 16·17·18로 변경 | 주석 뒷부분 제목들 |
| `V4_기수롤.dsd` | "제 60 기"→"제 61 기"·"제 59 기"→"제 60 기"(20곳) + 표지 기간 자동필드 연도 +1(4곳) | 표지·재무제표 머리글 |

## 각 파일마다 확인할 것 (파일당 2~3분)

1. **열기**: DART 편집기로 파일 열기 — 오류·경고 팝업이 뜨는가?
2. **표시**: 위 표의 "볼 위치"로 이동 — 깨짐·이상한 표시가 있는가?
   (V1은 복제 표가 온전히 보이는지, V2는 표가 삭제되고 주변이 자연스러운지,
   V3는 제목 번호가 바뀌었는지, V4는 기수·날짜가 +1 되었는지)
3. **미리보기**: 미리보기(뷰어)로 렌더링 — 페이지가 정상인가?
4. **재저장**: **다른 이름으로 저장** → 파일명 뒤에 `_저장본` 붙여 같은 폴더에 저장
   (예: `V1_표복제삽입_저장본.dsd`) — 저장이 되는가?
   ※ 저장본은 편집기가 내부적으로 뭘 고쳐 쓰는지 분석하는 데 씁니다 (중요).
